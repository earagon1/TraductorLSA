# Pantallas de entrada — rediseño

Mockups de las cinco pantallas iniciales de SeÑAR (splash, 3 pasos de onboarding
y pantalla de acceso) más la hoja de sistema visual.

- `*.dc.html` — un archivo por pantalla, editable como fuente.
- `canvas.json` — disposición de las pantallas en el lienzo.
- `senar-pantallas-de-entrada.html` — el lienzo armado, abrible en el navegador.

Todavía no hay código de la app tocado: esto es la propuesta de diseño previa
a la implementación en Compose.
